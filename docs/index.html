What is generated, and what is not

Every object in this scene was generated from a one-paragraph brief by an AI using the blender-model and blender-texture skills. Every build script and every brief is in the repo, linked below, beside the object it produced. Nothing was hand-edited after export.

That claim is about the objects. It is not about the sky, the lighting, the camera or this page, which are ordinary scene code and are listed below as such. The whole specification the objects were built to is ART-DIRECTION.md, and it was written before any of them existed.
